Upload the two original inspiration clips separately when the tool can inspect videos; the ZIP contains visual contact sheets and reference notes, not the original clips.

The prepared assets are portable. `assets/` is beside the prompt in the ZIP. In this repository they live under `docs/media/assets/`.

## Target and what has been prepared

The production brief targets 290 seconds / 8,700 frames at 30 fps, with a 160-second dedicated functional prototype block. It explicitly requires at least 150 actual functional-demo seconds after accounting for interruptions. This is a production plan, not a claim that a video or fresh app recording has already been created.

Prepared: the complete prompt, matching narration/cues, source PDFs/guideline, inspiration contact sheets, historical real UI stills, and six named portrait copies. The original portrait files are preserved at their supplied locations.

Still required for the final film: authentic interactive screen recordings, a coherent synthetic staff/patient flow, a genuine synthetic active-pass capture, generated fictional character references/keyframes, AI voice audio, licensed/original score and effects, and video rendering. The downstream production brief covers these dependencies and prohibits invented UI/results.
